# 🚀 Interactive Skills Showcase - 3D Experience

โปรเจคแสดงสกิลแบบ Interactive ที่มีลูกเล่นเยอะๆ พร้อมเกม mini-games และ 3D effects ที่น่าประทับใจ!

## ✨ Features เท่ๆ

### 🎮 **Interactive Games**
- **Code Typing Challenge** - ทดสอบความเร็วในการพิมพ์โค้ด
- **Memory Card Game** - เกมจับคู่สัญลักษณ์โปรแกรมมิ่ง
- **Code Puzzle** - เกมเรียงลำดับโค้ดให้ถูกต้อง

### 🎨 **Visual Effects**
- **3D Floating Cube** - ลูกบาศก์ 3D ที่หมุนได้
- **Particle System** - ระบบอนุภาคลอยในพื้นหลัง
- **Glassmorphism UI** - ดีไซน์แบบ Glassmorphism
- **Gradient Animations** - อนิเมชั่นไล่สีสวยงาม
- **Fireworks Effects** - เอฟเฟกต์พลุเมื่อเริ่มต้น

### 🎯 **Interactive Elements**
- **Animated Skill Bars** - แถบแสดงระดับความสามารถ
- **Hover Effects** - เอฟเฟกต์เมื่อเลื่อนเมาส์
- **Smooth Transitions** - การเปลี่ยนหน้าลื่นไหล
- **Responsive Design** - รองรับทุกขนาดหน้าจอ

## 🚀 Quick Start

### วิธีใช้งาน
1. **เปิดไฟล์** `index.html` ในเบราว์เซอร์
2. **คลิก "Start Experience"** เพื่อเริ่มต้น
3. **เล่นเกม** โดยคลิกที่ปุ่ม "Play Game" ในแต่ละสกิล
4. **สำรวจ** เกม mini-games ในหน้า Games

### การปรับแต่ง
```javascript
// เปลี่ยนข้อมูลส่วนตัว
const heroTitle = "Your Name";
const heroSubtitle = "Your Title";

// เปลี่ยนสกิล
const skills = [
    { name: "JavaScript", level: 95, icon: "fab fa-js-square" },
    { name: "React", level: 90, icon: "fab fa-react" },
    { name: "Python", level: 88, icon: "fab fa-python" }
];
```

## 🎨 Customization

### เปลี่ยนสีธีม
```css
:root {
    --primary-color: #00d4ff;
    --secondary-color: #ff6b6b;
    --accent-color: #00ff88;
}
```

### เพิ่มเกมใหม่
```javascript
// เพิ่มเกมใน switch case
case 'newgame':
    this.startNewGame(gameArea, gameTitle);
    break;
```
