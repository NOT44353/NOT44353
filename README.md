- **Tech Stack:** Next.js 16, React 19, Bun 1.3, TypeScript 5, Prisma 7, PostgreSQL (Aurora), AWS ECS Fargate, AWS Cognito PKCE OIDC, Tailwind CSS 4
- **Key Metrics:** 100% GxP Compliant, Zero Data Loss, Multi-step Approval Workflow

### 2. 🏭 ManHour Production Ecosystem & SAP Business One Sync
- **Overview:** สถาปัตยกรรมระบบคำนวณชั่วโมงทำงานและต้นทุนการผลิตในโรงงานผลิตยา เชื่อมต่อและซิงค์ข้อมูลแบบ Real-time 2 ทิศทางกับฐานข้อมูล SAP Business One (OWOR, Routing Stages)
- **Tech Stack:** Laravel 12 (PHP 8.4), MySQL, SAP MSSQL via ODBC/sqlsrv, Node.js ESM Sync Engine, .NET 8 Web API, Vite 7, Blade
- **Key Metrics:** 99.9% Uptime, Bidirectional SAP Data Pipeline, QR Code Job Ticket Tracking

### 3. 📄 E-Leaflet — Smart Drug Registration & Patient QR Platform
- **Overview:** แพลตฟอร์มเอกสารกำกับยาและระบบ QR Code สแกนดูข้อมูลยาสำหรับบุคลากรทางการแพทย์และผู้ป่วย รองรับการสตรีมไฟล์ PDF ความเร็วสูงผ่าน `PdfProxy` (HTTP Range Requests) พร้อมระบบแจ้งเตือนวันหมดอายุอัตโนมัติ
- **Tech Stack:** ASP.NET Core 8 Web API, C#, Entity Framework Core 8, MySQL, SQL Server, Razor MVC, PDF.js, JWT Authentication

### 4. 🚗 Car Share Mirror — MG S5 EV Screen Projection
- **Overview:** แอปพลิเคชัน Native Android Kotlin สื่อสารกับ Android Auto SDK โดยตรง เพื่อสะท้อนหน้าจอมือถือขึ้นหน้าปัดรถยนต์ไฟฟ้า MG S5 EV ขนาด 12.8 นิ้ว ผ่านสัญญาณไร้สาย โดยไม่ต้องเชื่อมต่อผ่าน Browser หรือ Hotspot

### 5. 📈 TD Master & JARVIS AI — Quant Trading & Autonomous CLI

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NOT44353/NOT44353.git
   cd NOT44353
   ```

2. **Open with live server / browser:**
   - Double click `index.html` or open directly in your browser:
     ```bash
     # macOS / Linux
     open index.html
     
     # Windows PowerShell
     Start-Process index.html
     ```
   - Or serve with any static local server (e.g., Live Server in VS Code, `npx serve`, or Python):
     ```bash
     python -m http.server 3000
     # Open http://localhost:3000
     ```
